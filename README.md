# 房貸可扣稅 ｜ 繼承取得房地附帶未償債務「額外負擔」減除核釋

本專案依據「重點速讀滑動卡片 ＋ 全文閱讀」雙模式規範製作，彙整並深入解析財政部 109 年 7 月 15 日台財稅字第 10904601200 號令，針對個人繼承房地且實際承受金融機構房貸時，日後出售得將超過公告現值部分列為「額外負擔」減除之規定與實戰試算。
